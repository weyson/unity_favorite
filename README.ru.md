# Избранное (Unity Editor)

**Languages:** [简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Русский](README.ru.md)

Пакет только для Editor: закладки на ресурсы и папки Project, категории, сворачивание и быстрый переход.

## Установка

### Способ 1: встроить в проект

Скопируйте репозиторий в `Packages/com.unityfavorite.favorites/` вашего Unity-проекта.

### Способ 2: Git URL (Package Manager)

```
https://github.com/weyson/unity_favorite.git
```

Если корень пакета — корень репозитория, добавьте этот URL. Можно использовать локальный путь: `file:D:/workspace/unity_favorite`.

## Использование

1. Открыть окно: `Window → 常用资源 → 常用资源`
2. **Справка**: кнопка `?` на панели или `Window → 常用资源 → 使用说明` (из справки можно открыть README текущего языка)
3. **Добавить**: перетащите из Project или ПКМ → `添加到常用` / `添加到常用（指定分类）`
4. **Категории**: «Новая категория»; ПКМ по заголовку — переименовать/удалить
5. **Сворачивание**: стрелка foldout (состояние сохраняется)
6. **Поиск**: фильтр по имени или пути; при поиске категории с совпадениями раскрываются
7. **Найти / открыть**: клик — ping; двойной клик — открыть (папки — ping); `↗` — проводник (для файла — родительская папка)
8. **Язык**: popup на панели (китайский упрощённый/традиционный, English, 日本語, 한국어, Русский; EditorPrefs)
9. **Очистка**: «Очистить» удаляет Missing

## Данные

`UserSettings/FavoritesData.json` в корне проекта (на пользователя и проект, обычно не в VCS). Ссылки по GUID — переименование и перемещение сохраняются.

## Ограничения

- Только ресурсы и папки в `Assets/`
- Без объектов Hierarchy, компонентов, пунктов меню, внешних файлов/URL
